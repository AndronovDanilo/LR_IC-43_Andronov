## Зміст лабораторних робіт

### Лабораторна робота №5 (`index.html` + `js/lesson-5.js`)
Реалізовано **19 завдань Варіанта №1** у 8 підтемах:
1. **1.1 Об’єкт (1, 9):** створення `student` та вкладеного `user.address`.
2. **1.2 Методи об’єкта (1, 8):** `Object.keys()`, поверхнева копія `Object.assign()`.
3. **1.3 Масив об’єктів (1, 7):** масив `students`, пошук товару за `id` і видалення через `splice()`.
4. **1.4 Деструктуризація об’єктів (1, 5, 10):** базова, `...rest`, вкладена деструктуризація відповіді сервера з перейменуванням.
5. **1.5 Callback-функції (1, 7):** `processValue(value, callback)` та відкладений виклик `setTimeout()` на 3000 мс.
6. **1.6 Стрілочні функції (1, 10):** `greeting` / `greetingArrow` та порівняння `this` у методі об’єкта `car.getInfo()` і стрілочній функції.
7. **1.7 Стрілочні функції як колбеки (1, 6, 9):** `processNumber`, слухач події `input` (`addEventListener('input', ...)`) у завданні 7.6 та `Promise` (`.then()` / `.catch()`).
8. **1.8 Перебираючі методи масиву (1, 5, 8):** `forEach()`, `findIndex()`, `reduce()`.

### Лабораторна робота №4 (`lab4.html` + `js/lesson-4.js`)
- **Завдання 1–3:** `prompt()`, `alert()`, шаблонні рядки у Console, `switch-case`, ідентифікація `Admin`/`User`.
- **Завдання 4–6:** чисті функції `makeTransaction(quantity, pricePerDroid)`, `checkForSpam(message)` та `filterArray(numbers, value)` з автоматичним виводом у Console.
- **Завдання 7 (Варіант 1):** генерація масиву заданої довжини, обмін максимального парного елемента та мінімального елемента з парним індексом, сортування за зростанням методом вставки (`insertionSort`).
- **Завдання 8:** двовимірний масив `4×4`, поділ на масиви додатних і від’ємних чисел, заміна 3-го додатного елемента.
